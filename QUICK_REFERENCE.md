# FlowPie — Quick Reference

## What is FlowPie?
FlowPie is a desktop data visualization tool for creating pie charts, bar charts, and arc ring charts from your data files. Drop in a spreadsheet or CSV, pick your columns, and get an interactive chart in seconds.

## Getting Started
1. Unzip the downloaded archive — you'll find `FlowPie.exe` and these two docs.
2. Double-click `FlowPie.exe` to launch. No installation required.
3. Drag a data file onto the drop zone, or use **File → Open File**.

## Supported Input Formats
| Format | Extensions |
|--------|-----------|
| Comma-separated | `.csv` |
| Tab-separated | `.tsv` |
| Excel | `.xlsx`, `.xls` |

## Main UI Areas
| Area | What it does |
|------|-------------|
| Drop Zone | Drag-and-drop files here to import data |
| Tab Bar | Each chart lives in its own tab; create as many as you need |
| Side Panel | Configure grouping, colors, labels, and series for the active chart |
| Chart Toolbar | New chart, export image, zoom controls |
| Status Bar | Shows current app state and messages |

## Chart Types
- **Pie Chart** — `Ctrl+P` or toolbar button
- **Bar Chart** — `Ctrl+B` or toolbar button
- **Arc Ring Chart** — concentric ring visualization, same toolbar

## Keyboard Shortcuts
| Action | Shortcut |
|--------|---------|
| Open data file | `Ctrl+O` |
| Open project | `Ctrl+Shift+O` |
| Save project | `Ctrl+S` |
| Save project as | `Ctrl+Shift+S` |
| Close tab | `Ctrl+W` |
| New pie chart | `Ctrl+P` |
| New bar chart | `Ctrl+B` |
| Zoom in | `Ctrl++` |
| Zoom out | `Ctrl+-` |
| Fit to window | `Ctrl+0` |
| Export image | `Ctrl+E` |

## Saving Your Work
- Projects are saved as `.fpie` files — this preserves all your charts, column selections, and styling.
- FlowPie auto-journals changes so your work can be recovered if the app closes unexpectedly.
